# 📊 Excel Sales Dashboard & Data Analysis

## Project Overview
This project demonstrates an end-to-end sales data analysis workflow using Microsoft Excel. The dataset is **fictional and created for portfolio demonstration purposes**.

The project covers data preparation, KPI analysis, product and regional performance, monthly trends, and an interactive-style dashboard.

## 🧰 Tools & Skills
- Microsoft Excel
- Data Cleaning & Preparation
- Pivot-style aggregation
- KPI Analysis
- Data Visualization
- Dashboard Design
- Business Insights

## 📁 Workbook Structure
- **Raw_Data** — Original fictional sales dataset
- **Clean_Data** — Prepared dataset used for analysis
- **Analysis** — KPI, monthly, product, and regional summaries
- **Dashboard** — Executive-style dashboard with charts and key insights

## 📈 Key Results
- Total Revenue: **$732,808.60**
- Total Profit: **$110,832.58**
- Profit Margin: **15.1%**
- Total Orders: **600**
- Units Sold: **2,716**
- Top Product by Revenue: **Laptop**
- Top Region by Revenue: **North**
- Strongest Month by Revenue: **Jan**

## 🔍 Analysis Performed
1. Organized and validated sales records.
2. Calculated revenue, cost, profit, and profit margin.
3. Summarized performance by month, product, and region.
4. Built KPI metrics for executive reporting.
5. Created charts for revenue and profit trends.
6. Identified key business insights from the data.

## 💡 Business Questions Answered
- Which products generate the most revenue?
- Which products generate the most profit?
- Which region performs best?
- Which months have the highest sales?
- What is the overall profit margin?
- How many orders and units were sold?

All sales records in this project are **synthetic/fictional** and are intended only for learning and portfolio demonstration.
